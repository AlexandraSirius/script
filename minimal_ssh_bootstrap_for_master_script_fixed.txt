МИНИМАЛЬНЫЙ BOOTSTRAP ДЛЯ ЗАПУСКА МАСТЕР-СКРИПТА ПО SSH
================================================================

Цель:
Вручную делаем ТОЛЬКО IP + SSH-доступ.
Все остальные настройки по заданию потом выполнит мастер-скрипт.

Должно работать с ISP:
ping -c 3 172.16.1.2
ping -c 3 172.16.2.2
ping -c 3 192.168.100.2
ping -c 3 192.168.30.2
ping -c 3 192.168.200.3

ssh net_admin@172.16.1.2
ssh net_admin@172.16.2.2
ssh root@192.168.100.2
ssh root@192.168.30.2
ssh root@192.168.200.3

Пароли:
VESR первый пароль admin: Admin1234
net_admin: P@ssw0rd
root Linux-машин: задаёшь сама через passwd root


------------------------------------------------------------
1. HQ-RTR — минимально для SSH
------------------------------------------------------------

В консоль HQ-RTR:

password Admin1234
commit
confirm
configure terminal
hostname hq-rtr.sirius-exam.org
username net_admin
 password P@ssw0rd
 privilege 15
exit
interface gigabitethernet 1/0/2
 ip firewall disable
 ip address 172.16.1.2/28
exit
ip route 0.0.0.0/0 172.16.1.1
ip ssh server
do commit
do confirm

Проверка с ISP:
ping -c 3 172.16.1.2
ssh net_admin@172.16.1.2

3. HQ-SRV — минимально для SSH
------------------------------------------------------------

В консоль HQ-SRV:

IF=$(ip -o link show | awk -F': ' '$2!="lo"{print $2; exit}')
nmcli con add type ethernet ifname "$IF" con-name HQ-SRV ipv4.addresses 192.168.100.2/27 ipv4.gateway 192.168.100.1 ipv4.method manual 2>/dev/null || true
nmcli con mod HQ-SRV ipv4.addresses 192.168.100.2/27 ipv4.gateway 192.168.100.1 ipv4.method manual
nmcli con up HQ-SRV

passwd root

sed -i 's/^#*PermitRootLogin.*/PermitRootLogin yes/' /etc/ssh/sshd_config
sed -i 's/^#*PasswordAuthentication.*/PasswordAuthentication yes/' /etc/ssh/sshd_config
grep -q '^Port 22' /etc/ssh/sshd_config || echo 'Port 22' >> /etc/ssh/sshd_config

ssh-keygen -A
sshd -t
systemctl enable --now sshd
systemctl restart sshd

Проверка на HQ-SRV:
ip -br a
ip route
ping -c 3 192.168.100.1

Проверка с ISP:
ping -c 3 192.168.100.2
ssh root@192.168.100.2

------------------------------------------------------------
Важно
------------------------------------------------------------

Если Linux-машина не пингует свой шлюз, скрипт дальше не отработает.

Шлюзы:
HQ-SRV -> 192.168.100.1
BR-SRV -> 192.168.30.1
HQ-CLI -> 192.168.200.1

Если с ISP не работает SSH, сначала чинить минимальный bootstrap,
а не запускать полный скрипт.
